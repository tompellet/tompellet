## About

I turn real-world needs into working software. Management tools, web apps, interactive interfaces, 3D on the web: I enjoy solving the technical side as much as polishing how things look.

I'm self-taught and learned by building, project after project. I've worked with AI every day for three years, and knowing how to use it well, steer it and verify what it produces is a real part of how I work.
