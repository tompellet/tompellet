### About me

I turn real-world needs into working software.

Management tools, web apps, interactive interfaces, 3D on the web: I enjoy solving the technical side as much as polishing how things look.

Self-taught, I learned by building. I've been working with AI every day for 3 years, and knowing how to use it well, steer it and check what it produces is a core part of how I work.
